# Stories — Radim Theiner

> A visual diary of everyday moments outside the main portfolio.

[Open the current diary](https://radim-theiner.com/stories.html) for event titles, dates, text, photographs, and looping videos. Stories are ordered by date, oldest at the top of the timeline and newest at the bottom. The page opens on the newest story unless a direct story link is supplied.

Use the timeline or Older/Newer controls to move between events; on touch devices, hold and slide the timeline. Select thumbnails to change the displayed photo or video. Direct event links use `https://radim-theiner.com/stories.html#<story-id>`.

This file describes navigation, not a cached list of events. Read the live diary for current content. Uploading, editing, and deleting are private owner functions, not public agent interfaces.
